A short history

🍎 In 1987, Apple shipped HyperCard, and software stopped being something only programmers made.

You drew a button, typed two lines of plain English, and that was the app. No project file. No compiler. Sounds familiar?

  • 👩‍🏫 Teachers wrote their own courseware
  • 🏛️ Museums ran kiosks on it
  • 🏝️ Myst was made in it

It came free on every Mac for over a decade. Then it was gone, and nothing quite took its place.

HyperLab picks the idea back up, with language models part of HyperTalk itself.

🕯️ Dedicated to Bill Atkinson (1951–2025), who wrote QuickDraw, MacPaint and HyperCard, and insisted the last of them ship free with every Mac.

Examples

Each opens in the playground, running. Switch to the edit tool to read the scripts that make it work.

  • Cluedo A drawn mansion with clickable rooms, and a case you close by deduction.
  • Myst An island, four Ages, and one book you should not open. Go ▸ Map finds the trap without running a line.
  • LLMs for n00bs Nine slides on how a language model works. The last one asks a real model, and says so plainly when none is set up.
  • Address Book A card per person, one shared background.
  • Recipe Box Chunk expressions doing arithmetic on the ingredients.
  • Todo A list, a dialog, and a loop.

AI

HyperLab works with no provider configured. AI ▸ Settings takes Anthropic, OpenAI, OpenRouter, a local Ollama, or a mock that answers offline.

Your API key stays in your browser. The site is static files; requests go from your browser directly to your provider, and no command reads a saved key back out. The sidebar shows the exact text of everything sent.

The assistant works through the same commands you do, so its changes are undoable like any other.

The desktop application

A .dmg, an .msi, and a .deb, .rpm or .AppImage on the releases page. A stack downloaded from the playground opens in the application; it is the same file.

Stacks export as a PDF, as a PNG of the map, as a self-contained web page, and as a Decker deck — from the playground as readily as from the application.

HyperLab is MIT-licensed and contains no Apple code and no Apple artwork; the resemblance is to the era.
